# Mohiuddin Shanto | Developer Portfolio

A professional, fully responsive personal portfolio website showcasing my skills, experience, and projects as a Next.js / React / WordPress developer.

**🔗 Live Site:** [https://mohiuddin-portfolio-omega.vercel.app/](https://mohiuddin-portfolio-omega.vercel.app/)

---

## 📌 Overview

This portfolio highlights my journey from a self-taught WordPress/WooCommerce developer to a full-stack developer working with the MERN stack and Next.js. It includes my work experience, Islamic education background, technical skills, and a showcase of my best projects.

## ✨ Features

- **Responsive Navbar** — Desktop navigation with active-link highlighting + mobile hamburger menu
- **Hero Section** — Professional designation, photo, typewriter animation, and animated stats
- **Resume Download** — One-click resume download button
- **Social Links** — GitHub, LinkedIn, Facebook, WhatsApp
- **About Me** — Programming journey, interests, and personality
- **Skills** — Categorized (Frontend, Backend & Database, WordPress & E-commerce) with animated progress bars
- **Education** — Islamic education background (Qawmi Madrasa track)
- **Experience** — Timeline of professional work history
- **Projects** — 6 featured projects in card format, each with a details modal showing:
  - Tech stack
  - Description
  - Live demo link
  - GitHub repository link
  - Challenges faced
  - Future improvements
- **WordPress Demos** — Showcase of 14+ client WooCommerce/Elementor sites
- **Contact Section** — Email (with copy-to-clipboard), phone/WhatsApp, and social links
- **Dark / Light Theme Toggle** — Persisted via `localStorage`
- **Smooth Animations** — Scroll reveal, custom cursor, particle background, scroll progress bar
- **Fully Responsive** — Optimized for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties (CSS variables) for theming, Grid & Flexbox, media queries
- **Vanilla JavaScript** — DOM manipulation, IntersectionObserver, Canvas particle animation, theme persistence
- **Font Awesome** — Icons
- **Google Fonts** — Syne & DM Sans

No frameworks or build tools required — pure HTML/CSS/JS.

## 📁 Project Structure

```
├── index.html      # Main HTML file (structure, content, and JS logic)
├── style.css        # External stylesheet
├── assets/           # Images, resume PDF, and other static assets
└── README.md
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mohiuddinshanto/<repo-name>.git
   ```
2. Navigate into the project folder:
   ```bash
   cd <repo-name>
   ```
3. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   npx serve .
   ```
